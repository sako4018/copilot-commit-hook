# copilot-commit-hook

Automatic commit messages for `git commit`. You only type:

```
git add .
git commit
git push
```

and the message is written for you as a [Conventional Commit](https://www.conventionalcommits.org/), for example:

```
feat(weather): add a screen that displays the forecast
```

The message is generated by [GitHub Copilot CLI](https://docs.github.com/en/copilot/how-tos/copilot-cli) from what you changed (`git diff --cached`). There is no editor screen: the commit goes through right away.

## Requirements

- macOS (tested) or Linux, with `git` and `perl` (both ship with macOS)
- Node.js 22 or newer
- A GitHub account with Copilot

## Install

```
npm install -g @github/copilot
copilot login

git clone https://github.com/sako4018/copilot-commit-hook.git
cd copilot-commit-hook
sh install.sh
```

`install.sh` copies two files into `~/.config/git/` and sets two global git settings (`core.hooksPath` and `core.editor`), so it works in all your projects. If you already have those settings, it does not overwrite them and tells you instead.

## How it works

- `hooks/prepare-commit-msg` is a git hook. Git runs it right before the commit message is saved. It sends your staged changes (up to 12,000 characters) to Copilot and writes the answer as the message.
- `hooks/auto-editor` tells git to accept the ready message without opening an editor. If the message is empty (no internet, an error, a used-up limit), it opens `nano` so you can type one yourself.

The rules for the messages (types, length, language) are written in the prompt inside `hooks/prepare-commit-msg`, so you can change them there. Types: `feat`, `fix`, `docs`, `style`, `refactor`, `perf`, `test`, `build`, `ci`, `chore`, `revert`.

## Don't like a message?

- Fix the last commit (only if you haven't pushed it yet):
  ```
  git commit --amend -m "new message"
  ```
- Write the message yourself for one commit: `git commit -m "my message"`. The hook leaves it alone.
- Skip the hook for one commit: `git -c core.hooksPath=/dev/null commit`

The hook does nothing for `-m`, `--amend`, merge, squash and rebase, and does nothing when nothing is staged. If anything goes wrong, the commit is never blocked.

## Limits

Each commit is one request to Copilot and counts against your Copilot plan. With small commits you are unlikely to hit the limit. If you do, the message stays empty and `nano` opens.

## Uninstall

```
sh uninstall.sh
```

This puts git back to its normal behavior. Copilot CLI stays installed; to remove it: `npm uninstall -g @github/copilot`.

## Good to know

- Your staged changes are sent to Copilot. Don't commit secret files or keys anyway.
- The scripts contain no keys or personal data. Your login is kept by Copilot CLI.
